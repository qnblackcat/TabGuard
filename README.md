# TabGuard

Control pop-ups and new tabs in Safari.

When a website tries to open a pop-up, TabGuard blocks it and shows a small banner above Safari's toolbar:
 - Allow Once
 - Always Allow Pop-ups on This Site
 - Block Pop-ups Silently: Whole Site, This Page Only, or This Pop-up Link


Whitelisted domains, blocked domains and blocked URLs can be managed, exported and imported in the tweak settings.

Inspired by SafariBlocker by P2KDev.

Tested on iOS 16.3.1 (rootless) and 17.1.1 (roothide). Should work on iOS 15 as well.
